## 🔧 Troubleshooting

| **Problem** | **Solution** |
|--------------|---------------|
| **Update fails** | Run as Admin |
| **Black screen after GPU update** | Boot to safe mode + rollback |
| **Audio broken** | Reinstall audio driver |
| **Network dropped** | Roll back NIC driver |
| **Scan stuck** | Restart service |
| **Restore point fails** | Enable System Protection |
